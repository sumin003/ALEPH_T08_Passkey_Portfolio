# ALEPH T08 — 패스키 등록

카드 2의 패스키 등록 구현입니다. 실제 기기 등록과 배포 환경변수는 별도 확인이 필요합니다.

- 기존 T08 저장소 위에 파일을 적용합니다. 기존 images/ 폴더는 유지하세요.
- DB 테이블과 함수는 이미 선택한 Supabase 프로젝트에 생성했습니다. docs/card2-schema.sql을 재실행하지 마세요.
- Node.js 24 환경에서 npm install --ignore-scripts로 의존성을 설치하고 package-lock.json을 생성해야 합니다.
- Vercel에서 SUPABASE_URL, SUPABASE_SECRET_KEY, T08_ORIGIN을 설정해야 실제 등록이 가능합니다.
- 현재 비공개 자료는 계속 잠겨 있습니다. 패스키 로그인은 카드 3에서 구현합니다.
- 구현 설명과 검사 범위: docs/CARD2.md

## 확인된 것

자동 검사 10개 통과. 카드 2의 암호 검증기는 테스트에서 모킹했으며 실제 기기 등록 통과를 의미하지 않습니다.
실제 DB에서 저장 트랜잭션·질문 재사용 거절·취소와 권한을 검사했습니다. 테스트 자료는 모두 롤백했습니다.

## 남은 확인

이 작업 환경의 npm registry 접근이 403으로 차단되어 의존성 설치·lockfile 생성과 실제 WebAuthn 검증은 미완료입니다.
실제 등록 창, 공개키 저장, 취소, 저장 위치는 HTTPS 배포 후 기기에서 확인해야 합니다.
